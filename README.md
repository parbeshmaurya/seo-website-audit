SEO Website Audit Skill

A Claude skill that audits a website for SEO and AI search visibility, then gives a prioritized fix list.

Get inputs 
Site URL
Business type (B2B / B2C / local / ecommerce / SaaS)
Main goal (leads, sales, calls, traffic)
Top 3 target keywords or services
Target country/city
2-3 competitors (optional)
Any data they can share: Search Console export, Ahrefs/Semrush audit, PageSpeed report
If a connected tool is available (Ahrefs, Semrush site audit, Search Console), use it first. Otherwise fetch pages directly and say which checks could not be done.

Report format
Summary (3-4 lines): overall health and the biggest problem.
Scores table: area, score, one-line reason.
Top 5 quick wins: what, where (URL), how to fix.
Full issue list: table with Issue | Page/URL | Why it matters | Fix | Impact | Effort.
30-day action plan: Week 1 to Week 4.
Not verified / data needed: list of checks that need Search Console, Ahrefs, Semrush or PageSpeed field data.
AI visibility test prompts (from step H).

What it checks
Technical SEO and indexation
Site structure and internal links
On-page (titles, meta, headings, images)
Content quality
Authority and trust (E-E-A-T)
Local SEO and brand consistency
Structured data (schema)
AI search visibility (AEO/GEO)
What you get
Short summary and scores per area
Top 5 quick wins
Full issue list with fix, impact and effort
30-day action plan
List of checks that need more data
Test prompts to track AI citations
How to install
Create a folder named website-audit.
Put SKILL.md inside it.
Zip the folder.
In Claude, go to Settings and open skills, then upload the zip.
How to use

Say something like:

"Audit https://example.com"
"Run a website audit for my client's site. They are a local B2C business."

Claude will ask for anything missing: URL, business type, goal, target keywords, country, competitors.

Get better results

Share any of these if you have them:

Search Console export (3-6 months)
Ahrefs or Semrush site audit
PageSpeed Insights report

Without them, Claude marks those checks as "Not verified" instead of guessing.

Rules built in
No made-up numbers or examples
Honest feedback, even if the site is weak
No page deletion advice without checking links and rankings
llms.txt is treated as optional, not a proven lever
